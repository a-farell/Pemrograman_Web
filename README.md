\# Sistem Manajemen Dokumen Kantin (Modul Penjual \& Kasir)



Proyek ini adalah implementasi antarmuka Sistem Informasi Manajemen Dokumen dengan desain monokrom yang compact. Sistem ini dirancang secara spesifik untuk memfasilitasi alur kerja internal guna menggantikan proses manual berbasis kertas. Dibangun menggunakan PHP Native, MySQL, Bootstrap 5, dan DataTables.



\## 🚀 Status Implementasi Fitur (100% Selesai)

\- \[x] \*\*Login:\*\* Autentikasi sesi (Session-based) membatasi akses berwenang.

\- \[x] \*\*CRUD + Upload Multiple File:\*\* Fungsionalitas penambahan laporan dengan unggahan file lampiran jamak. File disimpan ke direktori lokal dan direlasikan pada database MySQL. Fitur Update dan Delete berjalan sempurna.

\- \[x] \*\*Pencarian Data \& Datatable:\*\* Integrasi DataTables untuk fitur Search instan dan tombol Export (Excel, PDF, Print) dalam UI yang dioptimalkan.

\- \[x] \*\*Canvas untuk TTD Digital:\*\* Penggunaan SignaturePad.js untuk menangkap pengesahan dokumen (Base64).

\- \[x] \*\*Video / Animasi dan Audio:\*\* Menerapkan elemen `<audio>` berulang (loop) untuk latar, serta animasi CSS3 Keyframes (Fade-Slide-Up \& Pulse) guna meningkatkan UX.

\- \[x] \*\*Penggunaan Modal:\*\* Manipulasi form Create dan Update menggunakan Bootstrap Modal tanpa page reload.



\## 🛠️ Teknologi Pendukung

\* \*\*Back-End:\*\* PHP 8+, Database MySQL

\* \*\*Front-End:\*\* HTML5, CSS3, JavaScript, UI Framework Bootstrap 5
